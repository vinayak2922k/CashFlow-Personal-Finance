# CashFlow

A simple salary and expense tracker built for Prodesk IT Sprint 02.

## Features

- Set monthly salary
- Add / delete expenses
- Summary cards with live balance
- Low-balance warning (< 10% of salary)
- Doughnut chart (Chart.js)
- PDF report download (jsPDF)
- INR ↔ USD conversion
- LocalStorage persistence

## Stack

Vanilla HTML, CSS, JavaScript — no frameworks, no build step.

## Run

Open `index.html` in any browser.
